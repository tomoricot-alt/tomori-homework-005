# TOMORI HOMEWORK 使い方ガイド

宿題・提出物・テストの予定をまとめて管理できるアプリだよ。登録もチェックも、かんたん！

## はじめに
- 最初は「**サンプル**」と書かれた見本の予定が入っているよ。使い方を見たら、ホームの「**サンプルを消す**」で消そう。
- 名前や学校名などは入力しなくていいよ。
- 入れた内容は、**いま使っている端末のブラウザの中だけ**に保存されるよ。外には送られないよ。

## 予定を登録する
1. 画面の下の緑の **＋** を押す。
2. **種類**（宿題・提出物・テスト）をえらぶ。
3. **科目**をえらぶ（えらばなくてもOK。ない科目は自分で入力できるよ）。
4. **内容**を書く（例：ワーク p.24〜26）。※必須
5. **締切日**をえらぶ。「今日」「明日」「あさって」「1週間後」のボタンか、◀▶、カレンダーで決められるよ。※必須
6. **登録する** を押す。

## 画面の見方
- **ホーム**：「期限が過ぎている」「今日」「明日」「今週（日曜まで）」の順に表示。
  - 🔥 オレンジ色 … 今日・明日が締切。いそごう！
  - ⚠ 赤色 … 締切をすぎている（「◯日超過」）。いちばん先に片づけよう。
- **予定一覧**：締切の早い順、または科目ごとに見られるよ。「宿題」「提出物」「テスト」で絞りこみもできる。
- **完了履歴**：終わらせたものが残るよ。

## 終わったら
- 予定の左の **まる** を押すとチェックがついて完了！ ほめてくれるよ 🎉
- まちがえたら、出てくる「**取り消す**」を押すか、完了履歴のチェックをもう一度押すと未完了にもどるよ。

## 直す・消す
- 予定をタップすると編集できるよ。
- 編集画面の「**この予定を削除**」→「**削除する**」で消せるよ（もどせないので注意）。

## 大切なお知らせ
- ⚠ **ブラウザの「閲覧データの削除」「サイトデータの削除」をすると、記録が全部消えるよ。** 先生や家の人に聞いてからにしてね。
- ⚠ 「プライベートブラウズ」や別のブラウザ・別の端末では、記録は引きつがれないよ。
- 日付は、使っている端末の日付で決まるよ。日付が変わると、自動で「今日」が切りかわるよ。
- 通知（お知らせ音）の機能はまだないよ。ときどきホームを見に来てね。

## ホーム画面に追加する（iPhone）
Safari で開く → 共有ボタン → 「ホーム画面に追加」で、アプリのように使えるよ。
