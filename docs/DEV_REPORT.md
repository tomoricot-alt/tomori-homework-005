## 設計メモ
- 日付はローカル `YYYY-MM-DD` 文字列＋暦日計算。UTC変換による1日ずれを避けた。
- 「今日」は15秒ごと・フォーカス/表示復帰時に再確認し、0時またぎで自動更新。
- サンプルデータは `sample: true` で区別（「サンプル」バッジ）。消去後や保存済みの場合は再表示しない。
- 保存は AsyncStorage（Web では localStorage）。壊れたデータは別キーに退避し、画面に警告を表示。
- 削除は誤操作防止のため2段階確認（`window.confirm` に依存しない）。
